Software and equipment developed
•	Continued leading the development of the open source APPFL framework with 111 commits (23,103 lines of code added, and 6,030 lines of code removed), including 4 version releases on PyPI in the past fiscal year. Integrated new features such as support for memory-efficient communication for large foundation models, privacy-enhancing algorithms, multi-user globus compute endpoint, virtual simulator, keycloack authentication, agentic skills, federated GWAS, and integration into NERSC Spin. APPFL has received more than 180 stars and 40 forks on GitHub. 
•	Contributed to the design and the development of trac.appflx.link and forge.appflx.link, which host a web platform to authenticate users through keycloak, create secure federation, launch on-demand federated learning server with different backends (gRPC, globus compute, and IRI). 
•	Supervised the design and development of HiveWatch from scratch, a monitoring and visualization toolkit for distributed and federated training experiments. Over the past year, I have contributed 21 commits (7,129 lines of code added, and 12,8453 lines of code removed), including 2 version releases on PyPI. 
•	Contributed to the development of Apeiron with 6 commits (6,121 lines of code added and 07 lines of code removed). Apeiron is a continual learning framework that automatically detects concept drift in data streams and adapts models through JVP regularized retraining, as a research product of the ModCon BASE SIM (self-improving model) team. 
•	Contributed to the development of RADAR-II with 5 commits (4,049 lines of code added and 461 lines of code removed). It’s a federated, privacy-enhancing framework for radio follow-up of gravitational-wave events with features including accelerated federated inference, LLM-assisted GCN parsing, and agentic VLA scheduling.
