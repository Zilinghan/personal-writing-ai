Two ways to federate

Pick how your collaborators connect. Both run the same APPFL server code.

Clients connect to you

gRPC server in Jupyter

We start a private Jupyter server with a notebook that runs the APPFL gRPC server. We put a secure proxy in front of it so clients anywhere can reach it.

  • A Jupyter URL with its own one-time password
  • A public gRPC endpoint to share with clients
  • Change the algorithm, rounds or model right in the notebook

Best for: partners who run their own client script.

You reach out to clients

Globus Compute

The server sends training tasks to each client's Globus Compute endpoint and collects the results. Clients don't keep a long-lived connection open, which suits shared clusters.

  • Works with HPC clusters and firewalled machines
  • Clients just register a Globus Compute endpoint
  • The server coordinates every round for you

Best for: research computing sites and supercomputers.

From zero to a running federation

The gRPC path, step by step.

  1. 1

    Launch

    Sign in and click Launch. In a moment you get a Jupyter URL, its password, and the gRPC endpoint for your session.

  2. 2

    Start the server

    Open the notebook, set the model and the algorithm (for example FedAvg), and run it. The APPFL server starts behind our proxy.

  3. 3

    Invite clients

    Send the endpoint to your collaborators. They point their APPFL client config at it and start training on their own data.

What a client changes

One block in the client's APPFL config: replace the local address with your session's endpoint. Everything else (model, data loader, trainer) stays on the client's side.

Everything APPFL can do, without the setup

No servers to provision, ports to open or certificates to manage.

Private sessions

Each launch gets its own Jupyter server and a unique password.

Reachable from anywhere

The gRPC proxy gives your server a public address, so clients don't need a VPN.

Many algorithms

Use APPFL's synchronous and asynchronous aggregators, such as FedAvg, FedAsync and FedCompass.

Privacy options

Turn on APPFL's privacy and compression features from the server config.

Your model, your data

Bring any PyTorch model. Data never leaves the client machine.

From laptop to HPC

Mix clients over gRPC, or reach supercomputers through Globus Compute.
